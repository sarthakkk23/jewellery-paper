# Jaipur Jewellery Index

Free, independent figures on Jaipur's jewellery trade, from public records: export tables, US import data, emerald auction
results, wedding dates and gold rates. By Sarthak Oberoi, a data analyst in Jaipur.

**Site:** https://sarthakkk23.github.io/jaipur-jewellery-index/

This repo holds the built site only. Every figure, with its source, period and caveat, is in [`figures.json`](figures.json);
each is computed by code and recomputed by separate code before it goes up. Nothing here is for sale, and no business pays
to appear.

Part of [Jaipur Index](https://sarthakkk23.github.io/jaipur-index/), with the
[Jaipur Café Index](https://sarthakkk23.github.io/jaipur-cafe-pulse/).
